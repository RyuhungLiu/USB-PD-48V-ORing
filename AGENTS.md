# AGENTS.md

This file contains the rules followed by AI assistants working in this project (the 48V10+10A ORing main controller and related hardware).

## Language

- **Always reply to the user in Taiwan Traditional Chinese**, including explanations, tables, questions and summaries. This applies to chat replies only.
- Replies use Taiwan terminology and usage (not mainland Chinese terms).
- Repository content is written in English: code comments, documentation, commit messages, tags and release notes. Do not add Chinese text to any file in the repository.
- Proper nouns, part numbers, pin names, net names, code identifiers and commands stay as-is (for example `LM1_EN`, `LTC4359`, `BOARD_ORING_POLARITY`), both in replies and in repository content.
- Code comments follow the existing style of each file; keep them in English.
